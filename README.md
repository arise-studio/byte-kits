# Byte's kits

Source of https://arise-studio.github.io/byte-kits: one page per AI tool shown by Byte the Hacker Cat
(steps, exact prompt, official link, affiliate link when there is one, clearly marked).

Each episode is a front-matter-only file in `_kits/`, written automatically by the publishing pipeline.
Layouts are in `_layouts/`, served by GitHub Pages (Jekyll).
